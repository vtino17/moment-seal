# MomentSeal v0.3.0 release notes draft

Status: **blocked from publication pending independent approval and deployment-specific integration evidence**.

## Highlights

- Ed25519 signed receipts with canonical domain-separated payloads and independent receipt validation before signing.
- Async external signer interface and a hardened HashiCorp Vault Transit adapter.
- Lifecycle-aware trust stores for key rotation, validity windows, and revocation.
- HTTP conditional-mutation and PostgreSQL row-version adapters with typed conflicts.
- Property, schema, adversarial, end-to-end, real-service integration, coverage, performance, dependency, CodeQL, and OpenSSF Scorecard gates.
- Reproducible source archives, CycloneDX SBOMs, checksums, and Sigstore-backed GitHub attestations.

## Security notes

No publicly known runtime vulnerability is claimed as fixed by this draft. MomentSeal remains a production candidate until the release checklist is complete. It does not establish source truth, authorization correctness, or backend precondition enforcement on behalf of a host system.
