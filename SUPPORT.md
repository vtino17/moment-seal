# Support policy

MomentSeal is pre-1.0. Security fixes are provided for the latest release line only. Older releases should be treated as unsupported unless a GitHub Security Advisory explicitly says otherwise.

Use GitHub issues for reproducible non-sensitive defects and discussions. Use private vulnerability reporting for suspected security problems. Do not place credentials, private keys, personal data, customer plans, or undisclosed vulnerabilities in public issues.

There is no commercial uptime or response-time SLA. Production operators must own on-call coverage, rollback, key revocation, evidence retention, and backend availability.
